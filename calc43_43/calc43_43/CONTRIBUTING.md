# 贡献指南 (CONTRIBUTING)

感谢你对 calc43 感兴趣！以下是如何参与本项目的方式。

## 报告问题 (Issue)

发现 bug 或有新功能建议时，请点击仓库上方 **Issues → New Issue**，并说明：
- 问题描述 / 期望的行为
- 复现步骤
- 运行环境（Python 版本、操作系统）

## 提交代码 (Pull Request)

1. Fork 本仓库，并 `git clone` 到你的本地
2. 基于 `main` 创建功能分支：`git checkout -b feature-xxx`
3. 修改代码，确保 `python tests.py` 全部通过
4. 提交：`git commit -m "描述你的修改"`
5. 推送并发起 Pull Request 到 `main`

## 代码规范

- 函数需有中文或英文 docstring
- 新功能必须附带对应的单元测试
- 提交信息用简短的中文或英文描述修改内容
